\section{Motivation}
Let $G = (V,E)$ be a graph with a set of vertices $V$ and a set of edges $E \subseteq V \times V$. In graph theory, an independent set of a graph $G$ is defined as a subset of vertices $I$ such that no two vertices in $I$ are adjacent. The optimization problem of determining an independent set with the largest possible number of vertices is referred to as the maximum independent set (MIS) problem. The identification of a MIS of a graph is an essential component of many different algorithms such as the maximal coloring problem \cite{Luby}, coarsening in algebraic multigrid \cite{multigrid}. Consequently, advancements in algorithms solving the MIS problem can have a significant impact on multiple fields of computer science.\\ 
Furthermore, graphics processing units (GPUs) have emerged as a means of acceleration in the field of graph processing. The massive degree of parallelism that GPUs provide has the potential to significantly accelerate graph processing algorithms \cite{GPUs}. Moreover, there exist numerous different approaches for resolving the MIS problem. In the course of this project the Monte Carlo algorithm introduced by Luby \cite{Luby} and the Local-Max algorithm by Dahlum et al. \cite{local_max} are employed. \\   
This task description is structured as follows: first, two approaches to the MIS problem are presented shortly in Section 2. Section 3 outlines the objectives of the project and provides a rough timeline of the planned order of achievement of these objectives.
\section{Related Work}
In their study, Imanaga et al. \cite{Rel_Prio} present a parallel algorithm for GPUs that addresses the MIS problem. The algorithm they propose is based on the fundamental concepts of Luby's algorithm. Furthermore, the authors demonstrate that their algorithm has smaller execution times than other MIS algorithms for GPUs or CPUs on random graphs. Additionally, the solutions of their algorithm produced 22.6\%-38.5\% larger independent sets for large graph instances relative to the alternative algorithms used in their experiment. This illustrates the potential for implementing Luby's and other algorithms that solve the MIS problem on GPUs. \\
The Local-Max algorithm, as proposed by Dahlum et al. \cite{local_max}, is based on the ARW algorithm by Andrade et al. \cite{ARW}. By introducing on-the-fly reductions and by kernelizing reduction rules they achieved high-quality independent sets quickly using a CPU architecture. Applying these techniques on GPUs instead could further accelerate the process of finding large independent sets.
\section{Objectives of the project}
This section outlines the planned sequence of events for achieving the project's objectives. The primary goal is to implement Luby's algorithm for GPUs, followed by experiments that compare the implementation to other state-of-the-art algorithms for solving the MIS problem.\\
The plan for achieving this objective can be summarized as follows: first, the main functionalities of Luby's algorithm need to be implemented for GPUs. This step has already been completed at the current stage of development. For that, the Kokkos framework \cite{Kokkos,Kokkos_basic} is employed. The Kokkos framework enables the possibility of developing performance portable code that is capable of executing on a variety of architectures, particulary GPUs.\\
Creating a output file that represents which vertices are part of the determined MIS is the subsequent step. Next, the functionality for reading in input graph files must be added to actually execute the algorithm for different graph instances. Moreover, these input/output operations would enable users to actually utilize the produced algorithm. Additionally, this is crucial for conducting experiments that compare the produced algorithm to other MIS algorithms for GPUs or CPUs. \\
After that, the performance of the resulting implementation can be monitored closely on different graph instances. Based on the results, the algorithm can then be improved. Currently, the algorithm does not handle the case that the input graph could extend the limited memory of GPUs. Therefore, it is to be expected that the algorithm performs poorly for large graph instances or does not compute a solution at all. Thus, this potential issue needs to be addressed at this stage of development at latest. \\
Subsequently, the actual experiment for the project can be conducted, followed by an evaluation of the results. The experiment should evaluate the execution time and the size of the solution. Comparing these values to other state-of-the-art algorithms in order to provide a thorough analysis is an essential part of the experiment. Consequently, determining which other algorithms the proposed algorithm is compared to is a fundamental step at this stage of development. Additionally, comparing the achieved implementation for GPUs to the original algorithms for CPUs is another objective for the experiment. This can demonstrate the impact of the large degree of parallelism of GPUs on the execution time of MIS solving algorithms. The results of all the previous steps should then be documented and presented as part of the bachelor thesis. \\
Depending on the remaining time for the project, the application may be extended by including the Local-Max algorithm mentioned above. This would enable a even more thorough analysis of MIS algorithms. For that, the Local-Max algorithm must be implemented for GPUs, similarly to Luby's algorithm, using Kokkos. Subsequently, the application must be configured to allow the selection of either algorithm. Afterwards, the performance of this alternative algorithm must be monitored to identify potential improvements, which could then be enforced. Finally, the experiment could then be expanded conducting the same experiments on the additional algorithm. This marks the conclusion of the objectives planned to be achieved in the course of the project.
