\section{Motivation}
Let $G = (V,E)$ be a graph with a set of vertices $V$ and a set of edges $E$. A subset $I$ of vertices of $G$ such that no vertices in $I$ are adjacent is called independent set of $G$. The optimization problem of determining an independent set with the largest possible number of vertices is called the maximum independent set (MIS) problem. Finding a MIS of a graph is an essential part of many different algorithms such as the maximal coloring problem \cite{Luby}, coarsening in algebraic multigrid \cite{multigrid}. Therefore, advancements in algorithms solving the MIS problem can have a significant impact on different fields of computer science.\\ 
Furthermore, GPUs have emerged as a acceleration in the field of graph processing. Due to the massive degree of parallelism GPUs provide, the usage of GPUs can lead to the speedup of graph processing algorithms \cite{GPUs}. Moreover, there exist many different approaches to solving the MIS problem. In the course of this project the Monte Carlo algorithm introduced by Luby \cite{Luby} and the Local-Max algorithm by Dahlum et al. \cite{local_max} are implemented for GPUs, which marks the main goal of the project.\\   
This task description is structured as follows: first, a different approach on an algorithm solving the MIS problem on GPUs is presented shortly in Section 2. Section 3 presents the objectives of the project and outlines a rough timeline of in which order these objectives are planned to be achieved.
\section{Related Work}
Imanaga et al. \cite{Rel_Prio} present a parallel algorithm for GPUs that solves the MIS problem. The algorithm they propose is based on fundamental concepts of Luby's algorithm. Furthermore, they found that their algorithm has smaller execution times than other MIS algorithms for GPUs or CPUs on random graphs. Additionally, the solutions of their algorithm produced 22.6\%-38.5\% larger independent sets for large graph instances than the other algorithms used in their experiment. This illustrates the potential of implementing Luby's and other algorithms that solve the MIS problem on GPUs. 
\section{Objectives of the project}
This section forms a timeline of how the different objectives of the project are planned to be achieved. The main goal is to implement Luby's algorithm for GPUs, followed by experiments that compare the implementation to other state of art algorithms for solving the MIS problem.\\
The plan of how to achieve this goal can be summarized as follows: first, the main functionalities of Luby's algorithm need to be implemented for GPUs. This step is already achieved at the current stage of development. For that, the Kokkos framework \cite{Kokkos,Kokkos_basic} is used. Kokkos enables the possibility of writing performance portable code that runs on a variety of architectures, especially on GPUs.\\
Creating a output file that represents which vertices are part of the calculated MIS is the subsequent step. Next, the functionality of reading in input graph files needs to be added to actually run the algorithm for different graph instances. Moreover, these I/O-steps would enable users to actually use the produced algorithm. Additionally, this is crucial for conducting experiments which compare the produced algorithm to other MIS GPU or CPU algorithms. \\
After that, the performance of the resulting implementation can be monitored closely on different graph instances. Depending on the results the algorithm can then be improved. Currently, the algorithm does not handle the case that the input graph could extend the limited memory of GPUs. Therefore, it is to be expected that the algorithm performs poorly for large graph instances or does not compute a solution at all. Thus, this potential issue needs to be addressed at this stage of development at latest. \\
Subsequently, the actual experiments for the project can be conducted, followed by an evaluation of the experiments. The results of all the previous steps should then be documented and presented as part of the bachelor thesis. \\
Depending on the time left for the project the application can be extended by including the Local-Max algorithm mentioned above. This would enable a even more thorough analysis of MIS algorithms. For that the Local-Max algorithm needed to be implemented for GPUs, similarly to Luby's algorithm, using Kokkos. Afterwards, the performance of that alternative algorithm needs to be monitored leading to potential improvements. Finally, the experiment could then be expanded conducting the same experiments on the additional algorithm. This marks the end of the objectives planned to be achieved in the course of the project.
